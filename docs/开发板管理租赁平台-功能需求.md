# 开发板管理租赁平台 · 功能需求

> 项目：**ostool-server** · 版本 v1.0

---

## 1. 角色与权限

- **匿名访客**：浏览公开资源、文档、条款。
- **注册用户**：申请租赁、使用会话、上传镜像、串口调试。
- **管理员**：管理库存、用户、角色、电源、TFTP、服务器配置。
- **RBAC**：`roles` / `permissions` / `user_roles` / `role_permissions`，权限按模块分组。
- **账号开通**：支持自助注册 + 管理员开通两种途径；密码 ≥ 8 位；支持禁用、重置。
- **注册策略**（站点设置可配置）：
  - **关闭注册**：仅管理员可开通账号。
  - **自动生效**：注册成功立即激活，可登录。
  - **管理员审核**：注册后进入待审核状态，管理员审核通过后激活；用户可在注册页与登录页看到审核状态提示。
- **审核工作流**：管理员后台「待审核用户」列表，支持批量/单个通过、拒绝、补充备注，并通知用户。
- **防滥用**：注册需验证码（图形验证码 / 邮箱验证码，按策略启用）；同一邮箱/IP 限频。

---

## 2. 公共页面

- 首页、资源总览、文档、服务条款、隐私政策。
- 资源页：板型列表、在管/可用数、标签、搜索/过滤/排序、卡片与列表视图、空闲容量条。

---

## 3. 用户工作台

- **总览**：活跃租约数、会话数、快捷入口。
- **账户**：资料展示、修改密码。
- **我的租赁**：日历视图（时/日/月/年）、创建/释放/续租、列表与网格切换。
- **租约会话**：会话列表、进入会话详情（串口、文件、上下电）。
- **会话申请**：选板型、选时段（冲突高亮）、自动分配空闲板、返回会话 ID 与租约过期时间。

---

## 4. 会话与会话作用域

- **生命周期**：创建 → 已分配 → 运行中（心跳续租）→ 释放 / 过期 / 强制结束；结束自动回收板与清理临时文件。
- **会话能力**（以 session_id 隔离）：
  - WebSocket 串口通道
  - 会话文件上传/下载/删除（内核、ramfs、DTB）
  - TFTP 文件、UEFI HTTP Boot 镜像、boot profile
  - 电源控制与状态查询
- **启动模式**（按板型三选一）：
  - U-Boot + TFTP：`kernel_load_addr` / `fit_load_addr` / `bootm_addr` / `dtb_name` / `network_mode`
  - PXE
  - UEFI HTTP Boot：`boot_arch`、axloader，复用会话级存储
- 平台根据板型自动生成 bootcmd、加载地址、网络配置。

---

## 5. 管理后台

- **总览**：开发板/会话/用户/角色等关键指标与最近活动。
- **用户**：CRUD、角色分配、重置密码、禁用/启用；待审核用户列表（通过/拒绝/备注）。
- **角色与权限**：角色 CRUD、权限绑定、禁用。
- **开发板库存**：`board_configs` 为唯一权威源；字段含基础信息、串口（端口键/波特率）、电源管理、启动配置；运行态查询；串口端口与网卡探测。
- **租约**：全用户列表、代申请、改期、释放、强制结束、启停会话。
- **会话**：全平台列表、关闭/删除、上下文查看。
- **DTB**：元数据入库、二进制落盘、SHA-256、按板型匹配。
- **TFTP**：内置 / 系统 `tftpd-hpa` 切换、根目录/监听/选项、状态查询与对账。
- **服务器配置**：监听地址、数据/板/DTB/HTTP Boot 目录、网络接口（非环回）、上传限制。
- **站点设置**（运行时可改）：站点名、品牌、公告、维护模式、注册策略（关闭/自动生效/管理员审核）、自助租赁策略、租期上限、支持联系。

---

## 6. 电源与启动编排

- **电源后端**：自定义命令（`power_on_cmd` / `power_off_cmd`）或中盛继电器（串口键）。
- **启动编排**：自动生成 bootcmd 与网络参数；UEFI HTTP Boot 向 axloader 发送 boot offer。
- **安全**：电源/串口/TFTP 为操作敏感路径，副作用明确；敏感操作必须可审计；电源命令不得明文含敏感信息。

---

## 7. 文件与镜像

- **会话级文件**：会话隔离、结束清理、受 `session_file_max_mib` 限制。
- **DTB 库**：平台级、按板型匹配、元数据 + 落盘。
- **HTTP Boot 文件**：复用会话存储与生命周期。

---

## 8. 远程串口

- WebSocket 通道 `/api/v1/sessions/{id}/serial/ws`；
- 参数由板配置决定；同一会话独占；状态查询与诊断。

---

## 9. 审计与可观测

- `audit_logs`：管理动作、上下电、文件、用户/角色、租约/会话生命周期，含操作者/IP/UA/时间。
- `auth_sessions`：登录会话、撤销、过期、强制下线。
- 运行态诊断：TFTP 对账、串口/电源/运行态、配置自检。

---

## 10. 部署与运维

- 单一二进制 `ostool-server`（内嵌 Web UI）+ systemd 服务。
- 配置 `/etc/ostool-server/config.toml`，首启自动生成；默认 `0.0.0.0:2999`。
- 数据库：MySQL（生产）/ SQLite（开发）；路径归一化为绝对路径。
- 安装/升级脚本支持本地源与远程拉取。

---

## 11. API 与自动化

- REST API `/api/v1/*`：认证、公共资源、用户面（租约/会话/文件/串口/电源）、管理面（用户/角色/板/DTB/会话/租约/TFTP/配置/站点）。
- 与 ostool CLI 共用调度逻辑，可串入 CI 与回归验证。

---

## 12. 验收标准

1. 匿名访客可浏览资源、文档、条款。
2. 注册用户可完成：登录 → 申请租赁 → 创建会话 → 上传镜像 → 连接串口 → 上下电 → 启动 → 释放 全链路。
3. 管理员可完成：开通账号 → 配板/电源/启动 → 发布资源 → 监控租约 → 审计 全链路。
4. 会话过期或释放后板回可用池、临时文件清理。
5. 敏感操作有审计记录。
6. Linux + systemd 单机部署，配置即数据，二进制无外部依赖（除 DB）。
